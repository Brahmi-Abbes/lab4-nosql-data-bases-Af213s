## Résultats du Benchmark
| Technologie | Vitesse Écriture (ops/s) | Points Forts |
|-------------|-------------------------|--------------|
| Redis       | Très élevée             | Latence < 1ms |
| MongoDB     | Élevée                  | Flexibilité du schéma |
| Cassandra   | Excellente (écriture)   | Scalabilité horizontale |

## Synthèse
Le choix d'une base NoSQL dépend strictement du cas d'usage. Redis excelle pour le cache, MongoDB pour le contenu riche et varié, et Cassandra pour l'écriture massive de données temporelles.
